# 🎮 Kanvas

**https://nuffyofc.github.io/chillkanbanapp/**

A single-page Kanban Board + Note-Taker + Task Monitor. Built with HTML, Tailwind CSS, and Firebase Firestore.

### Features
- **Kanban Board** — drag-and-drop tasks across To Do, In Progress, Done columns
- **Quick Notes** — scratchpad with auto-save to the cloud
- **Task Monitor** — live completion stats with animated progress ring
- **Live Clock** — real-time display with timezone picker, auto-detects your location
- **Adaptive Hue** — app palette shifts with sunrise, day, noon, afternoon, sunset, evening, night
- **Playful UI** — capsule buttons, soft blues, checkerboard bg, float animations
- **Cloud Persistence** — all data synced to Firebase Firestore

### Tech Stack
- Tailwind CSS (CDN)
- Firebase Firestore (CDN compat)
- Native HTML5 Drag & Drop
